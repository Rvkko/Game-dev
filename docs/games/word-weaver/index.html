HOW TO PLAY
GUESS THE HIDDEN FIVE-LETTER WORD
Type a real five-letter word and press Enter. Every tile changes colour to tell you how close that letter is. Weave the clues together until the word is yours.

MODES

Daily Weave — one seeded puzzle a day, the same for every run of the game. Solve it to extend your daily streak. Hints are disabled here.
Unlimited — endless random puzzles with one hint available per puzzle.
Gauntlet — eight stages of steadily rarer words. Stages 1–3 give six guesses, 4–6 give five, 7–8 give four. You have three lives and a shared pool of three hints for the whole run. Clear all eight to bank the run bonus.

HARD MODE

With Hard Mode on, every clue you have already revealed must be used: green letters stay locked to their column and yellow letters must appear somewhere in each later guess. It can be toggled from Settings between puzzles.

CONTROLS

A–Z type a letter · Enter submit · Backspace delete · Space spend a hint · R restart the puzzle · Esc or P pause. The on-screen keyboard does everything the physical one does — tap or click any key.
