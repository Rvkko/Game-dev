THE RULES

🔢A revealed number is how many mines touch that square, counting all eight neighbours. Use the numbers to prove which hidden squares are mines.
🛡️Your first click is always safe — the mines are laid after it, never under it or the ring around it.
🏁You win when every square without a mine is uncovered. Flags are optional bookkeeping; they never win the game for you.

MOUSE

🖱️Left click — uncover a square. Uncovering a blank cascades outward automatically.
🚩Right click — plant / remove a flag (and a ? in between if question marks are on).
🎹Chord — press both buttons (or the middle button) on a number whose flags already match it, and every remaining neighbour opens at once. The fastest way to sweep — and the fastest way to die if a flag is wrong.
🔍Wheel zooms, Shift + drag pans a big field. Press 0 to refit the board.

KEYBOARD

⌨️W A S D / arrows move the cursor · Space uncover (or chord on a satisfied number) · F flag · H hint · R restart · T flag mode · M mute · Esc/P pause

SCORING

📈3BV is the minimum number of clicks a board can be solved in. 3BV/s is your speed rating, and efficiency is 3BV divided by the clicks you actually spent — chording is how you push it above 50%.
🧠No-Guess mode runs a constraint solver while generating and only hands you fields that logic alone can finish. Turn it on if you hate 50/50s.
💡A hint proves one safe square for you — but any board where you use a hint is not eligible for a record.
